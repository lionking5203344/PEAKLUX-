二、部署至 GitHub Pages
1. 登入自己的 GitHub 帳號，建立或開啟要使用的網站儲存庫。
2. 將本資料夾內的 index.html 與全部 JPG 圖片，一起上傳至儲存庫最外層。
   請勿再包一層 PEAKLUX_1027版 資料夾，首頁應直接位於最外層。
3. 儲存上傳內容（Commit changes）。
4. 開啟儲存庫 Settings → Pages。
5. Source 選 Deploy from a branch，分支選 main，資料夾選 / (root)，按 Save。
6. 等待 GitHub 顯示部署完成，再開啟 Pages 提供的網址。
7. 若更新現有網站，先保留舊版備份，確認要更新的檔案後再上傳。

三、部署至一般靜態網站主機
1. 在主機管理介面找到網站根目錄，常見名稱為 public_html、www 或網站發布目錄。
2. 將本資料夾內的 index.html 與全部圖片一起上傳到同一層。
3. 讓 index.html 成為網站首頁，保持檔名英文大小寫一致。
4. 開啟主機提供的網址，檢查文字、圖片、選單及 LINE 連結。
本網站是靜態網站，不需要資料庫或伺服器程式。

四、更新文字及圖片
網站目前沒有後台，修改內容需要編輯 index.html。
可用純文字編輯器編輯，並以 UTF-8 編碼儲存，避免中文亂碼。
修改前請先備份完整資料夾。
若更換圖片，使用相同檔名並維持適合的比例；若改檔名，必須同步修改 HTML 的圖片路徑。
更新後請同時檢查電腦及手機畫面。瀏覽器若仍顯示舊版，可重新整理或清除快取。

五、不可任意刪除的檔案
index.html 及上述八張 JPG 都是網站使用中的檔案，不可任意刪除或改名。
請維持相對位置，不要只上傳 index.html，否則圖片會消失。
本網站使用 Google Fonts 線上字體；有網路時會載入，未連線時使用系統替代字體。
LINE 及 Facebook 連結需要網路才能開啟。
